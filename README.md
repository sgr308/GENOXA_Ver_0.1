# GENOXA: Bulk RNA-Seq Analysis & Gene Modeling Platform

- GENOXA is an interactive **R Shiny–based platform for bulk RNA-Seq analysis** that integrates traditional differential expression pipelines with **machine learning–based gene modeling**.

- The application enables users to perform **end-to-end RNA-Seq data analysis without requiring programming expertise**. GENOXA combines widely used bioinformatics frameworks including **limma**, **edgeR**, **clusterProfiler**, and **caret**, within a unified graphical interface.

- GENOXA allows researchers to upload gene expression data, perform quality control, identify differentially expressed genes, conduct pathway enrichment analysis, and build predictive models using gene expression signatures.

---

# Overview

RNA-Seq analysis typically requires multiple software tools and programming expertise. GENOXA simplifies this workflow by providing a **no-code graphical environment** integrating multiple analytical stages into one interactive platform.

The application supports:

- Differential expression analysis  
- Exploratory data visualization  
- Gene Ontology enrichment analysis  
- KEGG pathway analysis  
- Machine learning–based gene prediction models  
- Automated analysis report generation  

GENOXA is designed for **biologists, bioinformaticians, clinicians, and students** who want to analyze RNA-Seq data quickly and reproducibly.

## Input Requirements

GENOXA accepts standard RNA-Seq count matrices.

**Required inputs:**

- **Gene expression count matrix (genes × samples)**  
- **Sample metadata table**

**Optional inputs:**

- Gene annotation or clinical/phenotype files

**Demo files for preparing your data (located in `www/` folder):**

- `www/Demo_counts.txt` – Example gene expression count matrix  
- `www/Demo_metadata.txt` – Example sample metadata table  
- `www/Demo_clinical_or_annotation.txt` – Optional example clinical/annotation data

You can use these demo files to format your own input data before running GENOXA.

# Installation

Clone the repository:

```bash
git clone https://github.com/sgr308/GENOXA.git
cd GENOXA
```

## Required R Packages

Before running **GENOXA**, all required R packages must be installed.  
The file **`01_library.R`** contains the complete list of libraries used by the application.

This file is automatically sourced when the application starts and loads all required dependencies.

# Running GENOXA

### 1. Using RStudio / Shiny
Start the application:
Open **app.R** in RStudio and click **Run App**.

Open your browser and navigate to: http://localhost:3838

### 2. GENOXA Online server

GENOXA is available online at:  
[https://sgrbnf.shinyapps.io/GENOXA/](https://sgrbnf.shinyapps.io/GENOXA/)

**Note:** The online version runs on a single CPU. For large datasets or intensive machine learning analysis, it may crash.  
We recommend running GENOXA **locally with ≥8 CPU cores** for reliable performance.
